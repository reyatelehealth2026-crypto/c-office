# GAN Design Evaluation Rubric

## Scoring Criteria

### 1. Design Quality (weight: 0.35)

**What to evaluate:** Visual excellence, color harmony, typography, spacing, and overall aesthetic appeal.

| Score | Description |
|-------|-------------|
| 9-10 | Award-worthy design. Beautiful color palette, perfect spacing, cohesive visual language. Would impress in a design portfolio. |
| 7-8 | Strong, professional design. Clean layout, good color choices, readable typography. Minor imperfections. |
| 5-6 | Functional but generic. Gets the job done but doesn't stand out. Safe but uninspired. |
| 3-4 | Cluttered or inconsistent. Mixed styles, poor spacing, hard to read. |
| 1-2 | Broken or unusable. Extreme visual problems. |

**Key questions:**
- Does the color palette feel warm and professional (NOT gamey/neon)?
- Is typography readable with good hierarchy?
- Do cards and panels have proper spacing and visual breathing room?
- Is the overall aesthetic cohesive (not mixing conflicting styles)?

### 2. Originality (weight: 0.30)

**What to evaluate:** Creative leaps, unique visual solutions, distinctive personality.

| Score | Description |
|-------|-------------|
| 9-10 | Surprising creative breakthrough. Unique layout, distinctive visual identity, memorable design moments. |
| 7-8 | Distinctive personality with some creative touches. Not a template — feels custom and thoughtful. |
| 5-6 | Clean but derivative. Looks like a standard dashboard template. Functional but not memorable. |
| 3-4 | Generic copy of common patterns. No personality or unique touches. |
| 1-2 | Boring or awkwardly different without purpose. |

**Key questions:**
- Does the design have a unique personality that distinguishes it from generic dashboards?
- Are there creative visual solutions for agent categories, task input, or activity display?
- Does it feel like a custom product, not a Bootstrap template?
- Is there a "signature moment" — a visually striking element that defines the app?

### 3. Craft (weight: 0.25)

**What to evaluate:** Implementation quality, CSS polish, animations, responsive behavior, attention to detail.

| Score | Description |
|-------|-------------|
| 9-10 | Pixel-perfect craft. Smooth animations, perfect alignment, beautiful hover states, polished transitions. |
| 7-8 | Well-crafted with attention to detail. Most interactions feel smooth and polished. |
| 5-6 | Solid implementation. Works correctly but lacks polish in animations and micro-interactions. |
| 3-4 | Rough implementation. Missing hover states, jarring transitions, alignment issues. |
| 1-2 | Broken CSS, layout issues, unstyled elements. |

**Key questions:**
- Are hover states, focus states, and transitions well-designed?
- Is the CSS well-structured with custom properties?
- Do animations enhance the experience (not distract)?
- Is the layout responsive and does it handle edge cases?

### 4. Functionality (weight: 0.10)

**What to evaluate:** Does the design support the core user workflows?

| Score | Description |
|-------|-------------|
| 9-10 | All workflows are intuitive and discoverable. Agent categorization, task dispatch, results viewing all feel natural. |
| 7-8 | Core workflows work well. Minor UX friction in some flows. |
| 5-6 | Basic functionality present but some flows are confusing. |
| 3-4 | Key workflows are broken or very hard to discover. |
| 1-2 | Design doesn't support the intended use cases. |

**Key questions:**
- Can a user immediately understand how to dispatch a task to a marketing agent?
- Is the agent-to-chat flow clear?
- Are quick action buttons visible and contextual?
- Is Thai + English bilingual support natural?

## Pass Threshold: 7.5 (weighted average)

## Special Bonuses (add up to +1.0 to final score)
- +0.3: Creative agent category visualization (not just a grid)
- +0.3: Beautiful task input experience (not just a boring textarea)
- +0.2: Smooth real-time activity updates with nice animations
- +0.2: Distinctive "signature moment" in the design

## Special Penalties (subtract from final score)
- -0.5: Still looks like a gacha/game theme
- -0.5: Neon purple/cyan color scheme retained
- -0.3: Game terminology still present (กิลด์, เควสต์, บอสฮันต์)
- -0.3: Layout is cluttered with too many panels
- -0.2: No clear agent-to-task workflow
